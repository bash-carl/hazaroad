# Release Notes - Hazaroad v1.0.0

## 🚀 HazaAI: Model & Core Update
This release provides the essential assets for the Hazaroad disaster monitoring system, including the local AI model for offline processing.

### 📦 Key Components
*   **HazaAI Model (Gemma 1B_Q4)**: The core AI model used by the app for offline hazard summarization.
*   **Hazard Monitoring System**: Initial stable release of the flood and road hazard tracking for Lopez, Quezon.
*   **Offline Support**: Full capability for device-side inference and local mapping.

### 📥 Usage
This release serves as the official host for the HazaAI model file. The application will automatically download and initialize the model from this release to enable intelligent offline reporting.
