# Hazaroad 🌊

**Hazaroad** is a specialized disaster monitoring and hazard reporting application designed for the community of **Lopez, Quezon**. It features **HazaAI**, an offline-first intelligence engine that helps summarize flood and road hazard reports even during connectivity outages.

## 🚀 Quick Download
You can download the latest build of the Hazaroad application and the required HazaAI model file from the official release page:

👉 [**Download Hazaroad & HazaAI Model**](https://github.com/bash-carl/haza-ai/releases/tag/hazaroad)

## ✨ Features
*   **HazaAI**: Local AI powered by Google Gemma 1B_Q4 for offline report summarization.
*   **Interactive Mapping**: Real-time hazard visualization for the Lopez, Quezon area.
*   **Weather Alerts**: Integrated local weather conditions and forecasts.
*   **Offline First**: Designed to work reliably during disasters when internet access is limited.

## 🤖 Powered by Gemma
This project leverages the **Gemma** open-weights model provided by **Google DeepMind** to bring sophisticated AI capabilities directly to mobile devices.
